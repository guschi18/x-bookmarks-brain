## Zusammenfassung

Das betrachtete Bild The Anatomy of an Agent Prompt zeigt eine vollständige Einkaufsvorlage für 40 ergonomische Bürostühle in San Francisco unter 20.000 Dollar, Lieferung binnen zwei Wochen. Goal, Return Format, Warnings und Context Dump gliedern den Prompt; drei Optionen werden vor dem Checkout zur Freigabe vorgelegt. Baselayer-Verifikation ist eine produktspezifische Vorgabe. Der Post nennt die Vorlage eine überarbeitete Fassung; ihre Zuschreibung an Greg Brockman ist nicht unabhängig belegt.
