## Zusammenfassung

X-Artikel von Leon Lin „A Large Resource Library for AI-Built React and React Native Interfaces“: Vibecodete Websites wirken generisch nicht wegen schwacher Modelle, sondern wegen schlechter Referenzen. Vor Prompts wie „make something modern“ solle man Inspiration sammeln, ein Komponentensystem wählen und dem Modell besseres visuelles Material geben. Der Artikel listet 160 verlinkte Ressourcen in neun Rubriken: Website- und UI-Inspiration (z. B. Godly, Awwwards, Refero, Mobbin), React-Komponenten (z. B. React Bits, Magic UI, 21st.dev, shadcn/ui), Shader/WebGL/Creative Coding (z. B. Three.js, Shadertoy, GSAP), Verläufe/SVGs/Hintergründe, Texturen und 3D-Assets, Bilder/Videos/Illustrationen, Icons, Schriften sowie React Native und mobile UI. Für React Native empfiehlt er Expo, React Native Reusables, gluestack und Reanimated. Ablauf: passende Referenzen finden, Screenshots, Flows und Komponenten speichern, dem Agenten geben, ein Komponentensystem statt Neugenerierung wählen und iterieren. Der Mobbin-Link ist als Affiliate-Link ausgewiesen.
