## Zusammenfassung

Daniel San verweist auf seinen dritten Wochenend-Artikel: Stripe-Workflow in [Claude Code](../entities/Claude%20Code.md) aus MCP, Skill und Permissions, abgesichert gegen ungewollte Schreibaktionen. [tweet-2114023867916112257](tweet-2114023867916112257.md)

Der gespeicherte Artikel beginnt mit der Aussage, Stripe bestätige nur einen Teil der Schreibaktionen; die Einstellung decke den Rest ab und gelte auch im Auto-Modus. Der Stripe-MCP-Server ist ein Remote-HTTP-Server unter mcp.stripe.com. Nach der Anmeldung kann Claude Code Kunden lesen, Abos anlegen, Rückerstattungen auslösen, Geld zwischen Treasury-Konten bewegen und eine Delaware-C-Corporation gründen. Lesetools seien harmlos, Schreibtools nicht, und das Modell behandle sie nicht unterschiedlich. [tweet-2114023867916112257](tweet-2114023867916112257.md)

Installation in einem Befehl über Claude Code Templates: `npx claude-code-templates@latest --mcp devtools/stripe --skill development/stripe-integration --setting permissions/stripe-mcp-confirm-writes`. Der Skill Stripe Integration liefert aktuelle Stripe-Hinweise (webhookgesteuerte Auslieferung, Idempotency Keys, Restricted Keys, Stripe Tax); die Einstellung Stripe MCP Confirm Writes ist das Bestätigungsstück. [tweet-2114023867916112257](tweet-2114023867916112257.md)
