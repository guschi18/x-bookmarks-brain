## Zusammenfassung

Der spanischsprachige Post stellt das Open-Source-Werkzeug book-to-skill vor, das ein Buch in eine Claude-Skill umwandelt: SKILL.md mit Kernkonzepten und Inhaltsverzeichnis, eine Datei pro Kapitel, Glossar, Dokument mit Techniken und Algorithmen sowie Kurzreferenz mit Regeln und Entscheidungstabellen. Kapitel werden nur bei Bedarf geladen; ein 400-Seiten-Buch brauche vollständig geladen etwa 200.000 Token. Das gespeicherte README-Bild nennt Unterstützung für GitHub Copilot CLI, Amp und [Claude Code](../entities/Claude%20Code.md), 24- bis 51-fach geringeren Tokenverbrauch und die Schritte Point, Distill, Load on demand. Die Repo-URL steht laut Post in den Kommentaren und fehlt im Raw; der separate Nutzer-Nachtrag ergänzt sie. Einordnung: [Book to Skill](../entities/Book%20to%20Skill.md).

## Nutzer-Nachtrag: Repository (2026-10-02)

Der Nutzer ergänzt [virgiliojr94/book-to-skill](https://github.com/virgiliojr94/book-to-skill). Die README wurde separat geprüft und ist kein Bestandteil des unveränderten Raw-Belegblocks. Sie nennt Installation per `npx skills add virgiliojr94/book-to-skill`, Aufruf mit `/book-to-skill <path|folder|glob> [skill-name]`, Unterstützung aller Hosts des offenen Agent-Skills-Standards (unter anderem GitHub Copilot CLI, Claude Code, Amp, Hermes Agent, OpenCode, OpenClaw), Eingabeformate von PDF über EPUB und DOCX bis Markdown sowie MIT-Lizenz für den Konverter.
