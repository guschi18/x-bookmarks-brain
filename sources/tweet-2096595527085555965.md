## Zusammenfassung

Rudrank Riyam kündigt App Store Connect CLI 5.0.0 als eines seiner größten Releases an. Gespeichert ist die README von rorkai/App-Store-Connect-CLI (asc): ein skriptbares CLI für die App Store Connect API zur Automatisierung von TestFlight, Builds, Einreichungen, Signierung, Analytics, Screenshots und Abonnements für iOS, macOS, tvOS und visionOS. Sie beschreibt Installation (Homebrew, Install-Skript, WinGet), API-Key-Anmeldung, TTY-abhängige Ausgabeformate, 25 per `asc install-skills` auf einen geprüften Commit gepinnte Agent-Skills, Release-Validierung inklusive Platzhalter-Lint, Telemetrie mit Opt-out und gängige Workflows. Release-Notes zu 5.0.0 sind nicht gespeichert.
