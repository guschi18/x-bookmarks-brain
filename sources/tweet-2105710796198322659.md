## Zusammenfassung

The stored [OpenDots README](https://github.com/CopilotKit/OpenDots) describes a self-hosted workspace template: Spaces, editable pages, specialist agents, conversations, optional computers, voice calls and Slack. It uses CopilotKit, AG-UI, TanStack AI and separate metadata/conversation stores. Setup uses Node 24, npm ci, .env and npm run dev. It is an early single-owner template, not a hosted product; Slack, spoken compute delegation and cloud learning delivery still require connected-service verification. The native demo transcript is empty. The quoted OpenAI dots announcement is not evidence of equivalent capabilities.
