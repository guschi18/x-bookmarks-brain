## Zusammenfassung

Der angeheftete Vorstellungspost von Leon Lin (16, München) nennt KI, Vibecoding, Design und Unternehmertum als Themen, verweist auf das in Arbeit befindliche Produkt Learn2Vibecode, seine Skills und das Nebenprojekt yourascii (Bild/Video zu ASCII) und distanziert sich von Meme-Coins in seinem Namen. Das Bild ist laut Beschreibung komplett schwarz.

Von Learn2Vibecode und yourascii sind nur kurze Landingpage-Texte gespeichert. Die vollständig gespeicherte README von Leonxlnx/taste-skill (https://github.com/Leonxlnx/taste-skill) beschreibt eine MIT-lizenzierte Sammlung von Agent Skills gegen generische KI-Oberflächen, installierbar über npx skills add, mit Varianten, drei Einstellreglern und Bildgenerierungs-Skills.

[Taste Skill](../entities/Taste%20Skill.md) beschreibt die Sammlung; [Design Skills for Coding Agents](../concepts/Design%20Skills%20for%20Coding%20Agents.md) ordnet sie ein. Die README enthält Sponsoren- und Affiliate-Hinweise; Qualitätswirkung ist nicht unabhängig geprüft.
