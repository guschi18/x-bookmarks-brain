## Zusammenfassung

Akshay beschreibt Memory Caching als Speicherung von RNN-Zuständen an Segmentgrenzen, auf die spätere Tokens zugreifen. Der Post unterscheidet Residual Memory, Gated Residual Memory, Memory Soup und Sparse Selective Caching und begrenzt die Experimente auf akademische Größen bis 1,3 Milliarden Parameter. Das Bild identifiziert arXiv:2602.24281v1. Die separat gelesene [Primärquelle](https://arxiv.org/abs/2602.24281), geprüft am 21.10.2026, bestätigt den Grundmechanismus und die weiterhin bessere Genauigkeit von Transformern bei schwierigen Recall-Aufgaben; keine unabhängige Replikation.
