## Zusammenfassung

Matt Shumer erklärt die Methode hinter seinem viralen Spiel „Claude of Duty“, das Claude Opus 5 in [Claude Code](../entities/Claude%20Code.md) aus einem einzigen Prompt gebaut habe: laut Artikel viele Stunden Laufzeit, eine große Subagenten-Flotte, rund 55.000 Codezeilen und alle Texturen, Meshes, Animationen und Sounds im Code erzeugt; Prompt und Code sind auf GitHub (mshumer/Claude-of-Duty) veröffentlicht. Die „Gauntlet Loop“: Ein Lead-Agent erhält Ziel und konkreten Referenzmaßstab, zerlegt die Arbeit in kleinste einzeln bewertbare Teile; je Teil arbeitet ein Builder, ein separater Critic mit frischem Kontext vergleicht das echte Artefakt blind mit der Referenz und schickt die größte Lücke zurück, ohne feste Rundenzahl. Optional sind eine Live-HTML-Fortschrittsseite und ein Glättungsdurchlauf nach jeder Welle. Der Artikel enthält ein Meta-Prompt-Template und empfiehlt Claude Code mit Opus 5 für visuelle Arbeit, [Codex](../entities/Codex.md) für Backend sowie ultracode. Einordnung: [Gauntlet Loop](../concepts/Gauntlet%20Loop.md).
