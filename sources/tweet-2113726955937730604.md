## Zusammenfassung

Der Autor warnt, dass Claude Code bei Nutzung von Git-Worktrees unbemerkt Speicher füllt, vor allem durch duplizierte node_modules. Sein Skill inventarisiert die Worktrees, erkennt sichere Kandidaten, zeigt den zurückholbaren Speicherplatz und fragt vor jedem Löschen nach. Installation laut Post: `npx claude-code-templates@latest --skill git/worktree-cleaner`. Das gespeicherte SKILL.md (MIT, Version 1.0.0) enthält die Regeln im Detail.
