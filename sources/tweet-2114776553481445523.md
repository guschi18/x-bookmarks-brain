## Zusammenfassung

Der Post des Chrome-Entwicklerkontos stellt klar, dass WebMCP MCP nicht ersetzt. MCP verbinde Agenten mit eigenen Diensten; WebMCP verbinde Agenten mit einer Website, solange sie geöffnet ist und der Nutzer eingebunden bleibt. Das angehängte Bild zeigt eine Vergleichstabelle MCP gegen WebMCP mit den Zeilen 'What it is', 'Where tools live' und 'UI'.
