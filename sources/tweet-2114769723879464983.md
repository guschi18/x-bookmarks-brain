## Zusammenfassung

Der Post veröffentlicht Hermit als Open Source, ein Framework für Continual Learning und RSI, das wiederverwendbare Adapter trainiert, ohne Modell oder Harness zu ändern. Die gespeicherte README definiert einen Harness-Adapter als trainierbaren externen Harness. Unterstützt sind GEPA, SkillOpt, MetaWorld Model, Harness² und Continual Harness; ACE und ReHarness sind angekündigt. Installation per `pip install hermit-harness`, Python 3.11 oder neuer.
