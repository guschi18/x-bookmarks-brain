## Zusammenfassung

Md Ismail Šojal stellt leanrea (github.com/aicodeking/leanrea) vor: ein 8-KB-Skill, der das Setup von [REA](../entities/REA.md) für Reverse Engineering durch einfache CLI-Tools ersetzen soll, ohne MCP-Server und ohne 207 Tool-Definitionen. Behauptet werden 38 % kürzere Laufzeit, 35 % geringere Kosten und rund 60 % weniger Tokens bei gleicher Genauigkeit. [tweet-2114160336114954401](tweet-2114160336114954401.md)

Die README nennt als Messaufbau Claude Code headless, Sonnet 5.5, macOS arm64, 4 Aufgaben x 3 Wiederholungen x 3 Varianten (leanrea 388 s, 2,17 USD, 74/75 Punkte; ohne Skill 479 s, 2,21 USD, 67/75; REA mit MCP 627 s, 3,36 USD, 75/75). Die Autoren nennen selbst Grenzen: nur 3 Wiederholungen, ein Modell, ein Rechner, kein Ghidra/Hopper/jadx; REA wurde mit Tool-Suche im Bestfall getestet. [tweet-2114160336114954401](tweet-2114160336114954401.md)

Installation laut README: `npx skills add aicodeking/leanrea`. [tweet-2114160336114954401](tweet-2114160336114954401.md)
