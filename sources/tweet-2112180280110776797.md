## Zusammenfassung

beamnxw beschreibt eine Motion-Design-Schleife mit Claude Code, Remotion und GSAP: Aus einer Bewegungsreferenz lässt Claude Code die Animation in sechs bearbeitbare Regler zerlegen (Spacing, Typografie, Motion Blur, Easing, Follow-through, Anticipation), die in einer Config liegen. Das Feedback wird so konkret (zum Beispiel vier Frames Anticipation hinzufügen). Genutzt wird die offizielle Remotion-GSAP-Integration (useGsapTimeline), die die GSAP-Timeline auf die Frame-Uhr von Remotion legt. Der zitierte Artikel bewirbt zusätzlich den KI-Mitarbeiter Viktor für das Studio-Geschäft; das ist Werbung. Details siehe [Agentic Video Production](../concepts/Agentic%20Video%20Production.md).
