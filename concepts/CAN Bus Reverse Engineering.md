# CAN Bus Reverse Engineering

## Gegenstand

Die [Awesome CAN Bus](../entities/Awesome%20CAN%20Bus.md)-Sammlung deckt das Beobachten und Rückentwickeln von CAN-Kommunikation an Fahrzeugsteuergeräten ab. Sie trennt Werkzeuge für Erfassung, Wiedergabe und Auswertung sowie Hardware-Schnittstellen. [tweet-2069287200164901209](../sources/tweet-2069287200164901209.md)

## Bausteine und Grenze

Die README führt Protokollbereiche wie OBD-II, UDS, ISO-TP und J1939 sowie DBC-Dateien zur Beschreibung von Nachrichten auf. Welche Kombination für ein bestimmtes Steuergerät funktioniert, belegt die Liste nicht. [tweet-2069287200164901209](../sources/tweet-2069287200164901209.md)
