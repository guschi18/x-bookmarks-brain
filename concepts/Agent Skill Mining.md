# Agent Skill Mining

## Verfahren

Die gespeicherte Paper-Zusammenfassung untersucht drei Schritte: GUI-Trajektorien segmentieren, Segmente zu Kandidaten-Skills clustern und eine skillbewusste Policy aus den Annotationen trainieren. Die Cluster sollen eine prüfbare Struktur der beobachteten Aufgaben zeigen. [tweet-2067986774241251433](../sources/tweet-2067986774241251433.md)

## Ergebnis und Grenze

Auf InteraSkill Workflows erreichen fünf von acht Clustern mindestens 0,95 Purity. GRPO verbessert die Skill-Schritt-Genauigkeit jedoch nur von 18,5 auf 20,5 Prozent, verändert BrowseComp+ kaum und liegt bei wichtigen Quellmetriken unter einfachen Häufigkeits-Baselines. Die Autoren nennen schwache Grenzerkennung, ungeordnete Segmentrepräsentation und ein Offline-Reward-Modell als Grenzen; lesbare Skills garantieren keinen Transfer.
