# Prefactoring

## Idee und Einsatz

Pococks Kent-Beck-inspirierter Prompt verlangt, vor der Implementierung Möglichkeiten zu suchen, den Code so vorzubereiten, dass die eigentliche Änderung leichter fällt. Der Vorschlag ist ein Planungsschritt innerhalb von [Agentic Engineering](Agentic%20Engineering.md). [tweet-2062139630955184170](../sources/tweet-2062139630955184170.md)

## Grenze

Die Quelle zeigt nur den Prompt und nennt keine konkrete Änderung, Tests oder gemessene Zeitersparnis. Sie begründet weder einen pauschalen Umbau vor jedem Ticket noch eine bestimmte Refactoring-Technik. [tweet-2062139630955184170](../sources/tweet-2062139630955184170.md)
