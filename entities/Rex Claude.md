# Rex Claude

## Überblick (Stand 2026-10)

Rex Claude ist laut Daniel Avila ein Skill für [Claude Code](Claude%20Code.md), mit dem Claude Panes und Tabs des Terminals Rex steuert. Er baute ihn, nachdem er länger mit Rex experimentiert hatte. [tweet-2116352019564777669](../sources/tweet-2116352019564777669.md)

## Funktionen laut Post

- Claude öffnet neue Panes und startet unabhängige Claude-Code-Sessions darin. [tweet-2116352019564777669](../sources/tweet-2116352019564777669.md)
- Sessions tauschen Anweisungen aus, überwachen Fortschritt und erkennen, wann eine andere Session fertig ist oder Aufmerksamkeit braucht. [tweet-2116352019564777669](../sources/tweet-2116352019564777669.md)
- Alles wird direkt aus Claude Code orchestriert. [tweet-2116352019564777669](../sources/tweet-2116352019564777669.md)

Installation: npx claude-code-templates@latest --skill productivity/rex-claude. [tweet-2116352019564777669](../sources/tweet-2116352019564777669.md)
