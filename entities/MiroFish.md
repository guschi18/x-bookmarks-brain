# MiroFish

## Rolle und Workflow (Stand 2026-05)

[MiroFish](https://github.com/666ghj/MiroFish) beschreibt sich als Multi-Agenten-Prognoseengine: Seed-Material und eine natürlichsprachliche Frage erzeugen eine simulierte Welt und einen Ergebnisbericht. Tausende interagierende Agenten mit Personas und Gedächtnis sind Projektangaben. [tweet-2056771925888696640](../sources/tweet-2056771925888696640.md)

Die README nennt GraphRAG-/Gedächtnisaufbau, Beziehungsextraktion und Persona-Konfiguration, parallele Simulation auf zwei Plattformen, ReportAgent und anschließende Gespräche mit Agenten in der simulierten Welt. OASIS von CAMEL-AI wird als zugrunde liegende Simulationsengine verlinkt. [tweet-2056771925888696640](../sources/tweet-2056771925888696640.md)

## Betrieb und Beispiele (Stand 2026-05)

Dokumentiert sind Node.js ≥18, Python 3.11–3.12, uv, ein OpenAI-SDK-kompatibler LLM-Zugang und Zep Cloud. Die README warnt vor hohem Verbrauch und empfiehlt zunächst weniger als 40 Simulationsrunden; npm run setup:all und npm run dev beziehungsweise Docker starten Frontend und Backend. [tweet-2056771925888696640](../sources/tweet-2056771925888696640.md)

Als Demos nennt sie öffentliche Meinungsbildung an der Wuhan University und ein mögliches Ende von Dream of the Red Chamber. Finanz- und politische Beispiele werden als künftig geplant beschrieben. [tweet-2056771925888696640](../sources/tweet-2056771925888696640.md)

## Aussagegrenze (Stand 2026-05)

„Predicting Anything“ und „high-fidelity“ sind Selbstdarstellung. README und GitHub-Screenshot belegen das Projekt und seinen geplanten Ablauf, aber keine out-of-sample Prognosegenauigkeit oder Kalibrierung gegenüber realen Ereignissen. Simulierte Interaktion darf aus dieser Quelle nicht als bestätigte Vorhersage gelesen werden. [tweet-2056771925888696640](../sources/tweet-2056771925888696640.md)
