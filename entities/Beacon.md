# Beacon

## Rolle

[Beacon](Beacon.md) (https://github.com/Asymptote-Labs/agent-beacon) beschreibt sich als lokal-first, quelloffener Memory-Layer für Coding-Agenten: Sitzungen aus [Claude Code](Claude%20Code.md), Cursor, [Codex](Codex.md), OpenCode, Cline und 20+ weiteren Harnesses werden erfasst und nützliche Workflows, Korrekturen und Debugging-Muster als wiederverwendbares Wissen bereitgestellt. [tweet-2104168233309974779](../sources/tweet-2104168233309974779.md)

## Dokumentierte Eigenschaften

- Exaktes Session-Replay mit Prompts, Antworten, Tools, Befehlen, Edits, Freigaben, MCP-Aktivität und Tokens. [tweet-2104168233309974779](../sources/tweet-2104168233309974779.md)
- Geprüftes Wissen soll künftigen Agenten über MCP oder Agent Skills zugänglich sein; Speicherung als JSONL ohne Harness-Lock-in. [tweet-2104168233309974779](../sources/tweet-2104168233309974779.md)
- Die interaktive Einrichtung meldet sich bei beacon.sh an und schlägt eine verwaltete Variante vor, mit ausdrücklicher lokaler Alternative; Installation per Homebrew oder Linux-Paket. [tweet-2104168233309974779](../sources/tweet-2104168233309974779.md)

## Verbindung zu Jev

Avi Chawla beschreibt Beacon als Umsetzung eines Memory-Promotion-Gates, bei dem [Jev](Jev.md) entscheidet, welche Korrekturen eine wiederverwendbare Lehre enthalten. Die README selbst nennt Jev im gespeicherten Auszug nicht. [tweet-2104168233309974779](../sources/tweet-2104168233309974779.md)

## Grenze

Wirkung auf Agentenqualität ist nicht gemessen; die Beschreibung stammt aus README und Autorenpost. [tweet-2104168233309974779](../sources/tweet-2104168233309974779.md)
