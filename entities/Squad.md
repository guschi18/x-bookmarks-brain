# Squad

## Rolle und Mechanismus

[Squad](Squad.md) wird in der gespeicherten README als Rust-CLI für die Koordination mehrerer Coding-Agenten beschrieben. Nachrichten, Aufgaben und Rollen wie Manager, Worker und Inspector laufen über Shell-Befehle und eine lokale SQLite-Datenbank; laut Projekt ist kein dauernder Daemon nötig. [tweet-2071274528177611047](../sources/tweet-2071274528177611047.md)

## Bedienung und Grenze

Die README nennt Initialisierung, Beitritt, Senden, Empfang sowie Aufgabenstatus und führt unter anderem [Claude Code](Claude%20Code.md), Gemini CLI, [Codex](Codex.md) CLI und OpenCode als Clients auf. Diese Funktionsliste ist eine Projektbeschreibung; die Quelle enthält keinen unabhängigen Test von Zuverlässigkeit oder Sicherheit.
