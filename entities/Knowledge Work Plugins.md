# Knowledge Work Plugins

## Überblick (Stand 2026-10)

anthropics/knowledge-work-plugins sind Plugins, die Claude für eine Rolle, ein Team und ein Unternehmen spezialisieren. Sie sind für [Claude Cowork](Claude%20Cowork.md) gebaut und laut README auch mit [Claude Code](Claude%20Code.md) kompatibel. Jedes Plugin bündelt Skills, Connectoren, Slash-Commands und Subagents für eine Berufsfunktion; die Plugins sind Markdown-Dateien und lassen sich per Fork anpassen. [tweet-2112110254024757276](../sources/tweet-2112110254024757276.md)

Die README nennt elf Plugins: productivity, sales, customer-support, product-management, marketing, legal, finance, data, enterprise-search, bio-research und cowork-plugin-management. Je Plugin sind Connectoren aufgeführt, etwa Slack, HubSpot oder Jira. [tweet-2112110254024757276](../sources/tweet-2112110254024757276.md)

Installation in Claude Code: claude plugin marketplace add anthropics/knowledge-work-plugins, dann zum Beispiel claude plugin install sales@knowledge-work-plugins. Die Plugins sind ein Beispiel für [Claude Plugins](Claude%20Plugins.md). [tweet-2112110254024757276](../sources/tweet-2112110254024757276.md)

Der Post nennt 30,3K Sterne; die Zahl stammt nicht aus der README. Die Plugins wurden hier nicht getestet. [tweet-2112110254024757276](../sources/tweet-2112110254024757276.md)
