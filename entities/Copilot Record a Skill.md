# Copilot Record a Skill

## Überblick (Stand 2026-10)

Record a Skill ist laut Microsoft-Artikel eine Funktion von Copilot in PowerPoint: Man nimmt eine Bearbeitungsaufgabe auf, statt Anweisungen zu schreiben, und Copilot entwirft daraus einen eigenen Skill, den man prüft, verfeinert und speichert. Die Idee ist, eine bekannte Arbeitsweise (zum Beispiel eine Tabelle aus Excel formatieren) wiederzuverwenden, ohne Prompts schreiben zu müssen. [tweet-2115901221181825265](../sources/tweet-2115901221181825265.md)

## Ablauf laut Artikel

1. Präsentation in Copilot in PowerPoint öffnen, dann + → Choose skills → Manage plugins & skills; unter Custom skills Add skill → Record a skill. [tweet-2115901221181825265](../sources/tweet-2115901221181825265.md)
2. Eine fokussierte Bearbeitungsaufgabe ausführen und Stop wählen. [tweet-2115901221181825265](../sources/tweet-2115901221181825265.md)
3. Den von Copilot entworfenen Skill prüfen und verfeinern. [tweet-2115901221181825265](../sources/tweet-2115901221181825265.md)
4. Mit Upload zur Wiederverwendung speichern. [tweet-2115901221181825265](../sources/tweet-2115901221181825265.md)

Empfehlung des Artikels: klein anfangen, eine Aufgabe mit klar sichtbarem Ergebnis wählen, etwa eine Tabelle oder ein Diagramm formatieren, und prüfen, dass der Entwurf die Absicht trifft. "Clean up the titles" ist als Aufgabenzuschnitt besser als alle Bearbeitungsgewohnheiten auf einmal. [tweet-2115901221181825265](../sources/tweet-2115901221181825265.md)
