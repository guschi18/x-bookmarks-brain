# Component Gallery

## Überblick (Stand 2026-03)

The Component Gallery (https://component.gallery/) ist eine Referenz für Oberflächenkomponenten auf Basis von Beispielen aus Design-Systemen; sie soll jedem dienen, der Interfaces baut. Zum Abruf am 2026-10-24 nennt die Startseite 60 Komponenten, 95 Design-Systeme und 2.671 Beispiele. [tweet-2028878637014057196](../sources/tweet-2028878637014057196.md)

Jede Komponente hat eine Seite mit Definition und Alternativnamen, etwa Accordion (auch Collapse, Disclosure, Expander), Carousel (Content-Slider), Popover (klickgesteuert, anders als ein Tooltip), Tree view, Rating, Quote, Pagination und Tabs. [tweet-2028878637014057196](../sources/tweet-2028878637014057196.md)

## Einsatz beim Vibe-Coding

Melvyn empfiehlt die Seite, weil die Kenntnis der Fachbegriffe die Frontend-Ergebnisse beim Vibe-Coding stark verbessere (Autorangabe "100x", nicht belegt). Sein Ablauf: Begriffe lernen, Beispiel als Screenshot sichern, damit umsetzen lassen. [tweet-2028878637014057196](../sources/tweet-2028878637014057196.md)
