# T3 Code

## Überblick (Stand 2026-10)

T3 Code (pingdotgg/t3code) nennt sich "agent harness control surface": Es steuert die Agents auf dem eigenen Rechner über eine Mobile-App (iOS, Android), eine Web-App und eine Electron-Desktop-App. Es nutzt die vorhandenen Abonnements von [Claude Code](Claude%20Code.md), Codex, Cursor, Grok Build, OpenCode und Google Antigravity, sofern sie lokal eingerichtet sind. [tweet-2112110254024757276](../sources/tweet-2112110254024757276.md)

Das README betont, nichts zu verkaufen; als Vorbilder nennt es die Codex-Desktop-App, Conductor, Claude Desktop und Cursor Glass. Installation: curl -fsSL https://t3.codes/install.sh | sh (Windows: irm https://t3.codes/install.ps1 | iex), dann t3; npx t3@latest startet ohne Installation. Mindestens ein Provider muss installiert und angemeldet sein. [tweet-2112110254024757276](../sources/tweet-2112110254024757276.md)

Der Post nennt 28,4K Sterne; diese Zahl stammt nicht aus der gespeicherten README. Verwandte Agent-GUIs: [PandaCode](PandaCode.md) und [Harp](Harp.md). [tweet-2112110254024757276](../sources/tweet-2112110254024757276.md)
