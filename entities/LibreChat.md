# LibreChat

## Plattform (Stand 2026-09)

[Repository](https://github.com/LibreChat-AI/LibreChat): selbst gehostete Chatoberfläche für Cloud-Anbieter und OpenAI-kompatible Endpunkte, einschließlich Ollama. Dokumentiert sind Agenten, [Model Context Protocol](../concepts/Model%20Context%20Protocol.md), Skills, Subagenten, File Search, Code Interpreter, Artefakte und Gesprächssuche. [tweet-2098941338297458746](../sources/tweet-2098941338297458746.md)

Die README nennt Mehrnutzer-Authentifizierung, Rollen-/Gruppenrechte, Administratoroberfläche und Docker-Deployment. Cloud-Modellnutzung bleibt von Anbieterzugang und Abrechnung abhängig. [tweet-2098941338297458746](../sources/tweet-2098941338297458746.md)

## Zwei gespeicherte Stände (Stand 2026-09)

Die Quelle enthält dieselbe Plattform unter danny-avila/LibreChat (v0.8.8-rc3) und LibreChat-AI/LibreChat (v0.8.8-rc4). rc3 nennt Agent Management API, experimentelle Code-Workspaces, manuelle Kompaktierung und Kontextverbrauch; rc4 ergänzt öffentliche API-Dokumentation, Trace Viewer und isolierte Gesprächs-Workspaces. [tweet-2098941338297458746](../sources/tweet-2098941338297458746.md)

Attached Workspaces sind ausdrücklich hoch experimentell. README-Funktions- und Sicherheitsangaben wurden hier nicht als geprüfte Deployment-Eigenschaften bestätigt; rc3 und rc4 bleiben getrennte gespeicherte Release-Stände. [tweet-2098941338297458746](../sources/tweet-2098941338297458746.md)
