# DeepTutor

## Rolle (Stand 2026-10)

DeepTutor ist ein quelloffener KI-Tutor der HKU (HKUDS) und läuft laut Post als Arbeitsbereich für Erklären, Üben, Tiefenrecherche und visuelle Erklärungen auf Basis eigener Lehrbücher, Skripte und Notizen. [tweet-2114702883673501719](../sources/tweet-2114702883673501719.md) Der Autor nennt rund 43.000 GitHub-Sterne; das belegt Popularität, keine Lernwirkung. [tweet-2114702883673501719](../sources/tweet-2114702883673501719.md)

## Eigenschaften laut Post

Das Gedächtnis hat drei Ebenen (Rohverlauf, Kernpunkte je Szenario, Gesamtprofil) und ist einsehbar und editierbar. [tweet-2114702883673501719](../sources/tweet-2114702883673501719.md) Bilibili- und YouTube-Links lassen sich einfügen, um zu bestimmten Sekunden nachzufragen. [tweet-2114702883673501719](../sources/tweet-2114702883673501719.md) Installation: `pip install -U deeptutor`, `deeptutor init`, `deeptutor start`; eine SKILL.md im Repo erlaubt Installation durch Claude Code oder Codex. [tweet-2114702883673501719](../sources/tweet-2114702883673501719.md)
