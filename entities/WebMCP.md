# WebMCP

## Abgrenzung zu MCP (Stand 2026-10)

Laut dem Chrome-Entwicklerkonto ersetzt WebMCP das MCP nicht. [tweet-2114776553481445523](../sources/tweet-2114776553481445523.md) MCP verbindet Agenten mit den eigenen Diensten. WebMCP verbindet Agenten mit einer Website, solange diese geöffnet ist und der Nutzer eingebunden bleibt. [tweet-2114776553481445523](../sources/tweet-2114776553481445523.md) Das angehängte Bild vergleicht beide in einer Tabelle nach 'What it is', 'Where tools live' und 'UI'; die Zellinhalte sind im gespeicherten Bildtext nicht vollständig wiedergegeben.
