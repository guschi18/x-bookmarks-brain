# Elaya Design Skills

## Repository und Umfang (Stand 2026-08)

https://github.com/elayadesign/ai-design-skills ist eine MIT-lizenzierte Sammlung eigenständiger Design-Skills. Die gespeicherte README enthält landing-page-design für Briefing, Seitenstruktur, Conversion-Texte und visuelle Regeln zu Typografie, Abständen, Radius und Bewegung. Für bestehende Websites verweist sie separat auf https://github.com/elayadesign/redesign-skill. [tweet-2085633290095202422](../sources/tweet-2085633290095202422.md)

Die README dokumentiert kopierte Skill-Ordner für [Claude Code](Claude%20Code.md), eine Regeln-Datei für Cursor und weitere agentenspezifische Übernahmewege. Das sind gespeicherte Installationshinweise, keine hier ausgeführte Installation oder geprüfte heutige Konfiguration. [tweet-2085633290095202422](../sources/tweet-2085633290095202422.md)

## Primärer Skill-Nachtrag (Stand 2026-10-12)

Der zusätzlich gelesene [landing-page-design/SKILL.md](https://github.com/elayadesign/ai-design-skills/blob/main/skills/landing-page-design/SKILL.md) beginnt mit einem Angebot, einer Zielgruppe und einer primären Aktion. Das Briefing fragt unter anderem nach Conversion-Ziel, Einwänden, Trafficquelle, Belegen und echten Assets. Dieser Online-Nachtrag ist vom August-Post und seinem unveränderten Raw-Beleg getrennt. [tweet-2085633290095202422](../sources/tweet-2085633290095202422.md)

Der Skill lässt ein begründetes Layout wählen, organisiert Hero, Nutzen, Ablauf, Belege, FAQ und Abschluss-CTA und empfiehlt abschnittsweise Umsetzung. Typografie, Abstände, Farben, Icons und Bewegung folgen einer bewusst eingeschränkten visuellen Vorgabe, nicht universell belegten Designregeln. [tweet-2085633290095202422](../sources/tweet-2085633290095202422.md)
