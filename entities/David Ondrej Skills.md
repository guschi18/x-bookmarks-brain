# David Ondrej Skills

## Sammlung und Struktur (Stand 2026-07)

Die gespeicherte README https://github.com/davidondrej/skills beschreibt Instruktionspakete für Coding-, Research- und Workflow-Agenten. Jeder Skill hat ein eigenes Verzeichnis mit SKILL.md; Kategorien sind agent-orchestration, skill-authoring, research-and-web, thinking-and-docs und ops-and-setup. [tweet-2074049148765016255](../sources/tweet-2074049148765016255.md)

## Verwendung und Grenzen (Stand 2026-07)

Als Aufgaben nennt die README Codeverbesserung, Inhalte, Recherche, Präsentationsreview und Transkripte. Viele Research-/Web-Skills werden DeepAPI zugeordnet; der gespeicherte Text ist ein Katalog, kein vollständiger Skill-Code und kein unabhängig geprüfter Production-Workflow. [tweet-2074049148765016255](../sources/tweet-2074049148765016255.md)

Die Sammlung ist ein weiteres Artefakt für [Agentic Engineering](../concepts/Agentic%20Engineering.md). Die umfassenden Tool-/Memory-/Reasoning-Versprechen des aktuellen Weiterverbreiters gehen über den Inhalt dieser kurzen README hinaus.
