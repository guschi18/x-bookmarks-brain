# DeerFlow

## Identifikation aus der Demo (Stand 2026-05)

Die visuell geprüfte stumme Demo zum Post zeigt DeerFlow 2.0. Die sichtbare README beschreibt einen Open-Source-Agenten-Harness, der Subagenten, Memory, Sandboxes und erweiterbare Skills orchestriert; die Demo zeigt unter anderem Recherche- und Inhaltsausgaben. [tweet-2053409004504961409](../sources/tweet-2053409004504961409.md)

## Ergänzender Primärquellenabgleich (Stand 2026-10, geprüft 2026-10-13)

Das [ByteDance-Repository](https://github.com/bytedance/deer-flow) bestätigt den Harness-Ansatz für Recherche, Code und weitere Artefakte. Die README grenzt 2.0 als Neuentwicklung vom auf dem 1.x-Branch gepflegten früheren Research-Framework ab. Der ergänzend gelesene Stand ist getrennt vom historischen Video. [tweet-2053409004504961409](../sources/tweet-2053409004504961409.md)

Die Modellkonfiguration dokumentiert lokale Endpunkte und externe Anbieter. Self-Hosting des Harness beweist deshalb keinen vollständig lokalen Gesamtworkflow; das hängt von den gewählten Modellen und Werkzeugen ab. [tweet-2053409004504961409](../sources/tweet-2053409004504961409.md)

## Grenzen der Ankündigung

Der Weiterverbreiter verspricht selbstständige 24x7-Arbeit und vollständig lokalen Betrieb. Der Post und die kurze Demo liefern dafür keine Messung oder getestete Konfiguration; das gespeicherte Video hat kein Sprachtranskript und Raw enthält keine README. Das Repository wurde ergänzend gelesen, nicht installiert. Der Ansatz gehört zu [Agentic Engineering](../concepts/Agentic%20Engineering.md).
