# OpenDuet

## Rolle (Stand 2026-10)

OpenDuet ist eine Open-Source-Vorlage von CopilotKit für einen proaktiven KI-Agenten, der selbst gehostet wird und mit beliebigen Agent-Harnesses arbeiten soll. [tweet-2115097056394240293](../sources/tweet-2115097056394240293.md) Der Post nennt Live-Assets, Freigaben durch den Menschen, Computer Use sowie Mobile, Web und Channels; Basis seien CopilotKit und AG-UI. [tweet-2115097056394240293](../sources/tweet-2115097056394240293.md) Der zitierte Post kündigt Claude Duet als Research Preview eines proaktiven Agenten an. [tweet-2115097056394240293](../sources/tweet-2115097056394240293.md)

## Funktionen laut README (Herstellerangaben)

Die README beschreibt eine Morgenübersicht, die Trennung von Dringendem und Aufschiebbarem über Mail, Kalender und Slack und Arbeit in einem eigenen Computer mit Browser und Dateien. [tweet-2115097056394240293](../sources/tweet-2115097056394240293.md) Vor Senden, Zahlen, Signieren und Löschen zeigt der Agent die Aktion und wartet auf Freigabe (einmal erlauben, immer erlauben, ablehnen). [tweet-2115097056394240293](../sources/tweet-2115097056394240293.md) Passwörter gehen über ein maskiertes Feld und erreichen nie die Konversation; ausgehende Nachrichten werden auf sensible Daten geprüft. [tweet-2115097056394240293](../sources/tweet-2115097056394240293.md)
