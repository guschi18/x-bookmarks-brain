# Amicro

## Rolle und Quellen (Stand 2026-10)

[Amicro](https://amicro.dev/) von Syed Subhan (SubhanHQ) ist laut Website eine kostenlose Open-Source-Sammlung von "160+ copy-paste React components" für Motion, Übergänge und UI-Effekte (Spring-Physik, Karten-Layouts, Loader, Mikro-Interaktionen wie Morph-, Glare-, Magnet- und Text-Reveal-Effekte). Das [GitHub-Repository](https://github.com/Subhan-code/Amicro--Micro-transitions-) steht unter MIT-Lizenz; der Post nennt 2,6k Sterne. [tweet-2112093680723214545](../sources/tweet-2112093680723214545.md)

Der Nutzer hat dieses Bookmark ausdrücklich wegen Amicro behalten. Der zweite im Raw gespeicherte Link (Jantar Mantar Chalo) stammt aus dem zitierten Post und ist ein unabhängiges Satire-Spiel. [tweet-2112093680723214545](../sources/tweet-2112093680723214545.md)

## Technik und Installation laut README (Stand 2026-10)

Die README beschreibt eine Kopier-in-dein-Projekt-Bibliothek auf Basis von Motion (`motion/react`) ohne Laufzeitabhängigkeit der kopierten Komponenten. Voraussetzungen: Node.js 18+, React 18 oder 19, Tailwind CSS v3 oder v4 und `motion` oder `framer-motion`. [tweet-2112093680723214545](../sources/tweet-2112093680723214545.md)

Installation per CLI: `npx @subhanhq/amicro@latest init`, danach `npx @subhanhq/amicro@latest add <name>` (zum Beispiel `download-button` oder `card-arc-5`). Alternativ über die shadcn-CLI mit dem Namensraum `@amicro` (zum Beispiel `npx shadcn add @amicro/fade-up`). [tweet-2112093680723214545](../sources/tweet-2112093680723214545.md)

Genannte Bausteine: Eintritts-Transitions (fade-in, fade-up, zoom-in), Hover und Text (tilt-card, magnetic-button, text-reveal), Hooks (use-scroll-progress, presets) und zwölf Karten-Layouts (Bogen, Fächer, Kaskade, Streuung, Wheel, Carousel, CoverFlow, Time-Machine-Stapel). Dark- und Light-Paletten werden unterstützt. [tweet-2112093680723214545](../sources/tweet-2112093680723214545.md)
