# Google Agents CLI

## Rolle

Die gespeicherte GitHub-README beschreibt [Google Agents CLI](Google%20Agents%20CLI.md) als Befehlszeile und Skill-Sammlung für Coding-Agenten, die ADK-Agenten erstellen, evaluieren, bereitstellen und in Gemini Enterprise registrieren sollen. Die README nennt sieben Skills für Workflow, ADK-Code, Scaffold, Evaluation, Deployment, Veröffentlichung und Observability. [tweet-2071509401224261823](../sources/tweet-2071509401224261823.md)

## Beispiel

Ein mit Google Cloud erstellter Artikel beschreibt einen RAG-Agenten: Scaffold aus einem ADK-Template, synthetischer Korpus, 20 Eval-Fälle, erkannte Anweisungslücke, Deployment auf Agent Runtime und Registrierung in Gemini Enterprise. Das ist ein vom Autor berichteter Einzelfall, kein unabhängiger Benchmark. [tweet-2071509401224261823](../sources/tweet-2071509401224261823.md)

## Grenze

Die Behauptung einer durchgängigen [Agentic Engineering](../concepts/Agentic%20Engineering.md)-Umgebung ist eine Produkt- und Autorenbeschreibung. Das beigefügte X-Video konnte nicht transkribiert werden; sein Inhalt ist hier nicht zusätzlich geprüft. [tweet-2071509401224261823](../sources/tweet-2071509401224261823.md)

## Einordnung im breiteren Google-Katalog (Stand 2026-05)

Die gespeicherte README von [Google Skills](Google%20Skills.md) verweist unter zusätzlichen Sammlungen für ADK-Skills auf google/agents-cli. Der umfassendere Katalog enthält daneben Cloud-, Ads- und Analytics-Skills und Plugins; er ist damit keine alternative Bezeichnung dieser CLI. Die dortigen Links belegen den Verweis, keine Installation oder Interoperabilitätsprüfung. [tweet-2054932165721293081](../sources/tweet-2054932165721293081.md)

## Ergänzender ADK-Workshop (Poststand 2026-05)

[Google ADK](Google%20ADK.md) dokumentiert einen älteren, direkt im Video beschriebenen Ablauf mit Geburtstagsplaner, MCP-Kalender und Agent-Engine-Deployment. Der Begleitpost bezeichnet ihn irreführend als Anthropic-Unternehmensbauplan; der Vortragende nennt Google Cloud. Der Workshop ist eine eigene Bedienquelle und ersetzt nicht den späteren CLI-/RAG-Ablauf. [tweet-2050939998115930192](../sources/tweet-2050939998115930192.md)
