# Addy Osmani Agent Skills

## Arbeitsabläufe (Stand 2026-09)

[Repository](https://github.com/addyosmani/agent-skills): 25 Skills, vier Reviewer-Personas, Checklisten und neun Lifecycle-Kommandos. Die README nennt /spec, /plan, /build, /test, /constraints, /review, /webperf, /code-simplify und /ship. [tweet-2098941338297458746](../sources/tweet-2098941338297458746.md)

Die Workflows enthalten Prozesse, Evidenzanforderungen und Tabellen gegen Ausreden; Referenzen werden bei Bedarf geladen. /build auto soll nach einer Planfreigabe alle Aufgaben ausführen, mit Verifikation und Stopp bei Fehlern oder riskanten Schritten. [tweet-2098941338297458746](../sources/tweet-2098941338297458746.md)

## Installation und Grenzen (Stand 2026-09)

npx skills add addyosmani/agent-skills installiert die Sammlung; --skill wählt einzelne Skills. Die README nennt native Integrationen für mehrere Coding-Agenten einschließlich [Codex](Codex.md) und [Claude Code](Claude%20Code.md). [tweet-2098941338297458746](../sources/tweet-2098941338297458746.md)

Einzelinstallation kopiert laut README nur skills/<name>/, nicht die gemeinsamen references/. Zusätzliche Checklisten können dadurch fehlen; vollständige Integration, Checkout oder gezieltes Kopieren sind die dokumentierten Lösungen. [tweet-2098941338297458746](../sources/tweet-2098941338297458746.md)

Die MIT-Lizenz und dokumentierten Verfahren belegen Wiederverwendbarkeit, keine gemessene Qualitätssteigerung.
