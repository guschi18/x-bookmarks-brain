# Hermit

## Rolle (Stand 2026-10)

Hermit ist ein Open-Source-Framework der Infini-AI-Lab für Continual Learning und RSI durch Harness-Adapter-Evolution. [tweet-2114769723879464983](../sources/tweet-2114769723879464983.md) Ein Harness-Adapter ist laut README ein trainierbarer externer Harness, der einen bestehenden Agenten an neue Aufgaben anpasst, ohne dessen Modell oder Harness zu ändern. [tweet-2114769723879464983](../sources/tweet-2114769723879464983.md)

## Methoden und Nutzung

Unterstützt sind GEPA, SkillOpt, MetaWorld Model, [Harness2](Harness2.md) und Continual Harness; ACE und ReHarness sind als kommend gelistet. [tweet-2114769723879464983](../sources/tweet-2114769723879464983.md) Die README nennt drei Vorteile: keine Änderung am Harness, Übertragbarkeit auf kompatible Modelle und Harnesses sowie Trainierbarkeit aus Aufgaben-Feedback. [tweet-2114769723879464983](../sources/tweet-2114769723879464983.md) Installation: Python 3.11 oder neuer, `pip install hermit-harness` oder aus dem Quellcode. [tweet-2114769723879464983](../sources/tweet-2114769723879464983.md)
