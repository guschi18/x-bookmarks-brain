# FinSkills

## Rolle und Aufbau

[FinSkills](FinSkills.md) ist laut gespeicherter GitHub-README eine Sammlung von 30 Finanzanalyse-Skills: jeweils 15 für US-Aktien und chinesische A-Shares. Das Projekt ordnet sie Screening, vertiefter Analyse, Portfolio/Dokumentation und einem Daten-Toolkit zu. [tweet-2069279465872425382](../sources/tweet-2069279465872425382.md)

## Dokumentierte Funktionen

- Die README nennt unter anderem Bewertung, Insiderhandel, Finanzberichte, Sektorrotation und Portfoliorisiko. Ein gemeinsames Toolkit soll Marktdaten und Berechnungen bereitstellen; die README nennt dafür Quellen wie SEC, FRED, yfinance und AKShare. Das sind Projektangaben. [tweet-2069279465872425382](../sources/tweet-2069279465872425382.md)
- Die Skill-Dateien werden als gestufte Anweisungen für Agenten beschrieben. Das Repository verknüpft sich mit der größeren OpenSkills-Sammlung. [tweet-2069279465872425382](../sources/tweet-2069279465872425382.md)

## Grenze

Die gespeicherte README dokumentiert Struktur und behauptete Fähigkeiten, aber keine unabhängige Validierung von Finanzanalysen oder Marktdatenqualität. [tweet-2069279465872425382](../sources/tweet-2069279465872425382.md)

## Ergänzender Finanzkatalog (Stand 2026-07)

[Awesome Finance MCP](Awesome%20Finance%20MCP.md) trennt Finanzdatenzugriff, Handelsausführung und Aufgaben-Skills und nennt Zugangsvoraussetzungen je Werkzeug. Das ergänzt den Blick auf Finanzanalyse-Sammlungen, liefert aber keinen Qualitätsvergleich oder Integrationsnachweis für FinSkills.
