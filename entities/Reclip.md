# Reclip

## Werkzeug (Stand 2026-08)

[averygan/reclip](https://github.com/averygan/reclip) beschreibt einen selbst gehosteten Open-Source-Downloader für Video und Audio. Die gespeicherte README nennt yt-dlp und FFmpeg als Download-/Konvertierungsgrundlage, Python/Flask als Backend und Vanilla HTML/CSS/JS ohne Build-Schritt als Oberfläche. [tweet-2088303030563135888](../sources/tweet-2088303030563135888.md)

## Ablauf

Eine oder mehrere URLs einfügen, MP4 oder MP3 wählen, mit Fetch Metadaten und Vorschaubilder laden, verfügbare Qualität wählen und einzeln oder gemeinsam herunterladen. Automatische URL-Deduplizierung soll wiederholte Eingaben abfangen. [tweet-2088303030563135888](../sources/tweet-2088303030563135888.md)

Die README zeigt Installation von yt-dlp/FFmpeg, Klonen des Repositories, Start mit ./reclip.sh und Zugriff auf localhost:8899; als Alternative ist Docker dokumentiert. [tweet-2088303030563135888](../sources/tweet-2088303030563135888.md)

## Grenzen

Die behaupteten mehr als 1.000 Plattformen beruhen auf yt-dlp-Unterstützung, nicht auf einem eigenen vollständigen Plattformtest. Die README nennt MIT und persönlichen Gebrauch; Installation und Downloads wurden hier nicht ausgeführt. [tweet-2088303030563135888](../sources/tweet-2088303030563135888.md)
