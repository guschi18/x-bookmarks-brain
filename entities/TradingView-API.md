# TradingView-API

## Funktionen laut README (Stand 2026-09)

[Repository](https://github.com/Mathieu2301/TradingView-API): Node-Bibliothek für Echtzeit-Marktkurse und Indikatorwerte von TradingView. Die README nennt automatisierte Backtests vieler Strategien und Einstellungen, technische Analyse, Datumsbereiche, Replay, Screener, Hotlists und Kalender. [tweet-2098946410079002681](../sources/tweet-2098946410079002681.md)

Weitere aufgeführte Funktionen sind Zugriff auf Zeichnungen und Invite-only-Indikatoren, mehrere gleichzeitige Indikatoren sowie Socket-Server-Emulation. Die Funktionen stehen unter einer Premium-Überschrift; Voraussetzungen und Leistungsumfang werden im kurzen README-Text nicht vollständig erläutert. [tweet-2098946410079002681](../sources/tweet-2098946410079002681.md)

## Installation und Beispiele (Stand 2026-09)

Der dokumentierte stabile Einstieg ist npm i @mathieuc/tradingview; für den Repository-Stand nennt die Anleitung npm i github:Mathieu2301/TradingView-API. Beispiele und Snippets liegen im Verzeichnis examples. [tweet-2098946410079002681](../sources/tweet-2098946410079002681.md)

Die README nennt Trading-Bots, Discord-Alerts, Backtests und ML-Indikatoren als mögliche Anwendungen. Das ist eine Bibliothek für programmatischen Zugriff; [OpenMarket](OpenMarket.md) ist dagegen eine separat belegte Marktoberfläche.
