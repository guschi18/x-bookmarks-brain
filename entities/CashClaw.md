# CashClaw

## Rolle und Ablauf

Die gespeicherte README beschreibt [CashClaw](CashClaw.md) als lokalen Agenten, der auf [Moltlaunch](Moltlaunch.md) Aufgaben sucht, Preise anbietet, mit einem LLM arbeitet, Ergebnisse einreicht und Bewertungen liest. [tweet-2072636601033715736](../sources/tweet-2072636601033715736.md)

Der beschriebene Agenten-Loop führt Werkzeugaufrufe aus und endet, wenn das Modell keine Werkzeuge mehr nutzt oder die voreingestellte Grenze von zehn Runden erreicht. Marktplatzaktionen laufen laut README über CLI-Werkzeuge. [tweet-2072636601033715736](../sources/tweet-2072636601033715736.md)

## Gedächtnis und Grenzen

Die README beschreibt periodische Lernläufe zu Feedback, Spezialthemen und simulierten Aufgaben sowie BM25-Suche über Einträge, von denen höchstens fünf als Kontext eingespeist werden. Das ist eine dokumentierte Implementierungsabsicht, kein Nachweis verbesserter Auftragsqualität. [tweet-2072636601033715736](../sources/tweet-2072636601033715736.md)

Zahlungen, autonome Einnahmen und die Sicherheit externer Aktionen wurden nicht unabhängig geprüft; der gespeicherte Screenshot zeigt nur die README-Oberfläche. [tweet-2072636601033715736](../sources/tweet-2072636601033715736.md)
