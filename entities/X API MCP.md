# X API MCP

## Rolle und Zugriff

Die X-Entwicklerdokumentation beschreibt einen gehosteten MCP-Server für API-Funktionen wie Suche, Nutzerabfrage und Bookmark-Verwaltung sowie einen separaten Server für API-Dokumentation. Der Zugriff auf das Konto folgt dessen Berechtigungen. [tweet-2071752389183647758](../sources/tweet-2071752389183647758.md)

## Einrichtung und Grenze

Für den kontobezogenen Zugriff beschreibt X eine lokale xurl-Bridge, eine eigene Developer-App und eine einmalige OAuth-Anmeldung; die Bridge erneuert danach Tokens. Ein App-only-Weg wird getrennt aufgeführt. Die gespeicherte Dokumentation belegt die angebotene Schnittstelle, aber keine erfolgreiche Verbindung in diesem Vault.
