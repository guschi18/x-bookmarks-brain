# Emil Kowalski Skills

## Sammlung und Einstieg (Stand 2026-08; gespeicherte README)

Das Repository https://github.com/emilkowalski/skills sammelt Design-/Engineering-Anweisungen für Coding-Agenten. Die gespeicherte README nennt die Installation `npx skills@latest add emilkowalski/skills` und verlinkt die jeweiligen SKILL.md-Dateien. ## Animationsablauf (Stand 2026-08)

Der Tweet beschreibt /find-animation-opportunities → /animate → /review-animations: geeignete Stellen finden, Animationen mit Kurve, Dauer und Eigenschaften erstellen, danach prüfen. Die README ergänzt /improve-animations für priorisierte Audit-Pläne und /animate-expo für React Native/Expo. [tweet-2084981497220456650](../sources/tweet-2084981497220456650.md)

Die README begründet Regeln mit konkreten Fehlern wie ease-in statt ease-out beim Einblenden und festen Rahmen statt halbtransparenten Schatten. Sie bietet außerdem emil-design-eng, animation-vocabulary, apple-design, write-swift, pick-ui-library, prototype und ask-sonner; die vollständigen Primärlinks stehen in der Source. [tweet-2084981497220456650](../sources/tweet-2084981497220456650.md)

## Einordnung und Beleggrenze

Die Sammlung ergänzt [Design Skills for Coding Agents](../concepts/Design%20Skills%20for%20Coding%20Agents.md) um Erstellung und Prüfung von Animationen. Die README enthält keine unabhängige Qualitätsmessung, und ihr gespeicherter Umfang belegt nicht die historische Verfügbarkeit aller Skills am 05.08.2026.
