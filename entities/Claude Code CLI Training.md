# Claude Code CLI Training

## Zweck und Zugang (Stand 2026-05)

Daniel San stellt https://claude-code-cli-training.vercel.app/ als interaktiven Einstieg in [Claude Code](Claude%20Code.md) im Terminal vor. Lektionen und schrittweise Befehle sollen das Bedienmodell ohne Tokenverbrauch vermitteln; Letzteres ist die Aussage des Autors. [tweet-2053648691798409555](../sources/tweet-2053648691798409555.md)

## Sichtbarer Lernablauf (Stand 2026-05)

Die beim Triage-Review visuell geprüfte stumme Demo zeigt einen simulierten Terminalablauf: Anmeldung, Start mit claude, ein erster Prompt zur Erklärung des Projekts, /rename und /exit. Der sichtbare historische Clientstand ist v2.1.138. [tweet-2053648691798409555](../sources/tweet-2053648691798409555.md)

Die [öffentliche Installationslektion](https://claude-code-cli-training.vercel.app/) nennt claude --version zum Versionscheck, claude doctor zur Diagnose und claude update zur Aktualisierung. Diese ergänzend gelesene Seite wird nicht rückwirkend dem Mai-Post zugeschrieben. [tweet-2053648691798409555](../sources/tweet-2053648691798409555.md)
