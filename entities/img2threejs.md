# img2threejs

## Überblick (Stand 2026-10)

img2threejs rekonstruiert Referenzbilder als animationsbereite Three.js-Modelle, die live im Browser laufen. Laut README entstehen die Modelle aus Primitiven, prozeduralen Shadern und generierter Geometrie, ohne Mesh-Dateien. Der Post beschreibt es als Werkzeug, bei dem ein Agent ein Foto eines Objekts erhält und es als 3D-Modell in Code nachbaut. [tweet-2112110254024757276](../sources/tweet-2112110254024757276.md)

Die README führt eine Demo-Galerie (img2threejs.io) mit Modellen wie Tropeninsel, Roboter-Studio, Schneedorf-Minispiel, Gitarre und Raumschiff, jeweils mit Live-Ansicht und generiertem Quellcode. Erweiterungen liegen als Plugins vor, etwa character, environment, hello-cube und img2glb. Die Skill-Schritte klassifizieren das Objekt, bewerten die Komplexität, erzeugen eine Qualitätsvereinbarung, die Three.js-Gruppe und Kamera- und Projektionsvorgaben. [tweet-2112110254024757276](../sources/tweet-2112110254024757276.md)
