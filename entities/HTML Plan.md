# HTML Plan

## Installation (Stand 2026-10)

Thariq nennt diese Installation aus dem Community-Marketplace für [Claude Code](Claude%20Code.md): [tweet-2107192972983075241](../sources/tweet-2107192972983075241.md)

```text
claude plugin marketplace add anthropics/claude-plugins-community
claude plugin install html-plan@claude-community
```

## Bedienung laut Primärnachtrag (README geprüft 2026-10-12)

Das [offizielle README](https://github.com/anthropics/claude-plugins-community/blob/main/html-plan/README.md), separat vom gespeicherten Tweet geprüft, beschreibt /html-plan als einzelne HTML-Seite mit einem aufklappbaren Baum: Nutzereffekt, Funktionsweise und konkrete Codeposition. UI-Mockups, Zustandsmaschinen, Call-Stacks, Schemas und Snippets bilden die Ebenen. [tweet-2107192972983075241](../sources/tweet-2107192972983075241.md)

Entscheidungen werden nummeriert; Nutzer wählen Optionen, bearbeiten ein Schema oder kommentieren Aussagen. Respond bündelt die Antworten zum Zurückkopieren an Claude. Node packt die Seite in eine Datei; weitere Abhängigkeiten nennt das README nicht. [tweet-2107192972983075241](../sources/tweet-2107192972983075241.md)

## Einordnung und Beleggrenze (Stand 2026-10)

[HTML as LLM Output](../concepts/HTML%20as%20LLM%20Output.md) umfasst auch Erklär- und Übersichtsartefakte; HTML Plan richtet den HTML-Output hier gezielt auf Planentscheidungen und deren Rückgabe. Installation und Ablauf wurden nicht praktisch ausgeführt. [tweet-2107192972983075241](../sources/tweet-2107192972983075241.md)
