# GEO SEO

## Zweck und Quelle (Post Stand 2026-03; gespeicherte README separat)

[geo-seo-claude](https://github.com/zubair-trabzada/geo-seo-claude) von zubair-trabzada ist laut README ein Skill-/Python-Werkzeug für [Claude Code](Claude%20Code.md), das GEO-Prüfungen mit technischen SEO-Grundlagen verbindet. Es ist ein anderes Repository als [SEO and GEO Skills Library](SEO%20and%20GEO%20Skills%20Library.md) von aaron-he-zhu; der gespeicherte README-Umfang ist kein gesicherter Release-Stand vom Tweetdatum. [tweet-2030864180417356230](../sources/tweet-2030864180417356230.md)

## Nutzbare Befehle

- /geo audit <url> orchestriert Entdeckung und fünf Analyseagenten für Sichtbarkeit, Plattformen, Technik, Inhalt und Schema; /geo quick <url> liefert laut README einen Kurzcheck. [tweet-2030864180417356230](../sources/tweet-2030864180417356230.md)
- /geo citability, /geo crawlers und /geo llmstxt prüfen Zitierbarkeit, robots.txt-Zugriff und llms.txt; /geo brands und /geo platforms ergänzen Erwähnungen und plattformspezifische Vorschläge. [tweet-2030864180417356230](../sources/tweet-2030864180417356230.md)
- /geo schema, /geo technical und /geo content betreffen strukturierte Daten, technische Grundlagen und Inhaltsqualität; /geo report und /geo report-pdf erzeugen Berichte. [tweet-2030864180417356230](../sources/tweet-2030864180417356230.md)

## Installation und Daten

Die README verlangt Python ab 3.8, Git und Claude Code. Unter Windows ist Git Bash statt PowerShell/CMD vorgesehen: Repository klonen und ./install-win.sh ausführen. Python-Abhängigkeiten liegen in einer eigenen Umgebung unter ~/.claude/skills/geo/.venv/. Die Befehle wurden nicht installiert oder getestet. [tweet-2030864180417356230](../sources/tweet-2030864180417356230.md)

Prospect-, Proposal- und Compare-Funktionen speichern Daten unter ~/.geo-prospects/; laut README entfernt der Uninstaller diese Kundendaten nicht. Die vollständigen Dateipfade und drei strukturierten Zusatzlinks bleiben im Quellenbeleg erhalten. [tweet-2030864180417356230](../sources/tweet-2030864180417356230.md)

## Bewertung und Evidenzgrenze

Die interne Score-Gewichtung beträgt 25 Prozent Zitierbarkeit/Sichtbarkeit, je 20 Prozent Markenautorität und Inhaltsqualität, 15 Prozent technische Grundlagen sowie je 10 Prozent strukturierte Daten und Plattformoptimierung. Diese Heuristik ist keine gemessene Suchmaschinen-Rankingformel. Markt-, Traffic-, Conversion- und optimale Passagenlängen sind unbestätigte README-Behauptungen. [tweet-2030864180417356230](../sources/tweet-2030864180417356230.md)

[Generative Search Optimization](../concepts/Generative%20Search%20Optimization.md) grenzt Googles dokumentierte Anforderungen von Tool-Empfehlungen ab. Insbesondere beweist die llms.txt-Funktion keinen Nutzen oder eine Pflicht für Google Search; die README deckt auch andere Antwortmaschinen ab. [tweet-2030864180417356230](../sources/tweet-2030864180417356230.md)
