# Google Skills

## Sammlung (Stand 2026-05)

[google/skills](https://github.com/google/skills) enthält laut gespeicherter README Agent Skills für Google-Produkte und -Technologien, einschließlich Google Cloud. Das Repository steht nach eigener Angabe unter aktiver Entwicklung und Apache 2.0; der kurze spanische Post liefert den Repository-Link, die README den Katalog. [tweet-2054932165721293081](../sources/tweet-2054932165721293081.md)

## Installation und Umfang

Die README nennt npx skills add google/skills mit Auswahl einzelner Skills. Bereiche umfassen Cloud-Onboarding und Authentifizierung, Lösungsarchitektur, Agentenbau/-deployment, AI/ML, GKE-Infrastruktur, Datenbanken, Observability, Sicherheits-/Identitätsaufgaben sowie Webhosting. Weitere Gruppen behandeln Ads-SDKs, Audience/Event-Ingestion und Analytics-APIs. [tweet-2054932165721293081](../sources/tweet-2054932165721293081.md)

Beispiele sind RAG-Unternehmenssuche mit GKE/AlloyDB, Agent-Platform-Evaluation, Model-Tuning und Prompt-/RAG-Management sowie GKE-Fehlerdiagnose und Kostenanalyse. Der Body verlinkt 124 strukturierte Einträge, aber enthält keine vollständigen Skill-Dateien oder ausgeführten Workflows. [tweet-2054932165721293081](../sources/tweet-2054932165721293081.md)

## Plugins und benachbarte Projekte

Das Repository bündelt nach eigener Beschreibung auch Plugins aus Skills und MCP-Servern. Der gespeicherte Text nennt Marketplace-Installation für [Claude Code](Claude%20Code.md), einen Marketplace mit Plugin-Browser für [Codex](Codex.md) sowie Installation per URL in Antigravity CLI; diese Befehle sind Dokumentinhalt, keine im Ingest geprüften Installationen. [tweet-2054932165721293081](../sources/tweet-2054932165721293081.md)

Unter zusätzlichen Sammlungen nennt es Android, Dart, Flutter, Firestore, Genkit, Maps und ADK-Skills. Der ADK-Verweis führt zu [Google Agents CLI](Google%20Agents%20CLI.md), das damit ein ergänzendes Projekt im Katalog und kein zweiter Name für dieses gesamte Repository ist. [tweet-2054932165721293081](../sources/tweet-2054932165721293081.md)
