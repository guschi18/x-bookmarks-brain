# Google Colab VS Code

## Sichtbarer Ablauf (Stand 2026-05)

Die visuell geprüfte Demo zeigt Googles Colab-Erweiterung in VS Code, ein lokales Notebook, die Auswahl eines Colab-CPU-Kernels und ausgeführte Pandas-Zellen. Der historische Screenshot nennt bei der Verbindung New Colab Server. Die Demo belegt keinen T4-GPU-Lauf. [tweet-2053772065149423648](../sources/tweet-2053772065149423648.md)

## Ergänzender Herstellerabgleich (Stand 2026-10, geprüft 2026-10-13)

Die [offizielle README](https://github.com/googlecolab/colab-vscode/blob/main/README.md) beschreibt eine auf der Jupyter-Erweiterung aufbauende Anbindung von Colab-Servern in VS Code. Ihr Quickstart lautet: Erweiterung installieren, Notebook öffnen oder erstellen, anmelden und Select Kernel → Colab → Auto Connect wählen. Dieser spätere Wortlaut ersetzt nicht die historische Demo-Beschriftung. [tweet-2053772065149423648](../sources/tweet-2053772065149423648.md)

## Ressourcen und Grenzen

Die [Google-FAQ](https://research.google.com/colaboratory/faq.html), ergänzend am 13.10.2026 gelesen, beschreibt variable GPU-Typen, Verfügbarkeit und Nutzungsgrenzen. Kostenlose Ressourcen und insbesondere eine bestimmte T4 sind nicht garantiert; die pauschale T4-Zusage des Posts ist daher keine verlässliche Hardwarezusage. [tweet-2053772065149423648](../sources/tweet-2053772065149423648.md)
