## Von einem Thema zur Originalquelle

Öffne zum Beispiel [Context Engineering](concepts/Context%20Engineering.md). Lies einen Abschnitt, der dich interessiert, und folge seinem Quellenlink. Die Quellenseite fasst den Beitrag zusammen und verlinkt den Originalpost. Prüfe dort den Kontext und das Veröffentlichungsdatum, bevor du eine Empfehlung übernimmst.

## In Obsidian öffnen

1. Wähle oben auf der GitHub-Seite **Code → Download ZIP**. Wenn du Git verwendest, kannst du das Repository stattdessen klonen.
2. Entpacke das ZIP in einen eigenen Ordner.
3. Wähle in Obsidian **Ordner als Vault öffnen** und öffne diesen Ordner.

Mit der Volltextsuche findest du Begriffe auch innerhalb der Seiten. Rückverweise zeigen, welche anderen Seiten auf das aktuelle Thema verweisen. Im lokalen Graphen siehst du die benachbarten Themen; die Verbindungen sind Seitenlinks und keine Bestätigung der Aussagen.

## Neue Stände herunterladen

Wenn du Git verwendest, führe im geklonten Ordner `git pull --ff-only` aus. Wenn du ein ZIP heruntergeladen hast, lade die neue Ausgabe erneut herunter und entpacke sie in einen neuen Ordner. Sichere eigene Notizen vor dem Wechsel.
